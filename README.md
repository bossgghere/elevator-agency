# elevator-agency

Executive Penthouse Suite & Digital Studio for **Gourav Raut** — Founder of [One Day Studio](https://onedaystudio.in) and [11ven](https://11ven.store), AI Full-Stack Developer at Algo Chowk.

## ✨ Highlights
- **Scroll-Driven Elevator Reveal**: Dual brushed bronze doors parting smoothly to reveal the Level 42 panoramic penthouse suite and creative lab.
- **Milestone Toast Animation**: Physics-based clinking glasses celebrating zero-downtime production deployments.
- **Direct Cal.com Scheduling**: Integrated booking modal wired to `samosa.wtf/15min`.
- **Curated Projects Showcase**: Real live client platforms including SnapLay (10K+ downloads), AlgoTrade, 11ven Store, SpectraQ, Makerble, Renard, and Outceedo.
- **Eager Web Audio Synthesis**: Penthouse arrival chime and crystal clink synthesized natively using the browser Web Audio API.
- **Floating Live Booking Beacon**: Quick 1-click scheduling trigger with live availability status.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Modern CSS3 (GPU transforms `translate3d`/`scale3d`, glassmorphism, responsive clamp)
- **Audio**: Web Audio API (zero external mp3 assets, purely synthesized oscillators)
- **Scheduling**: Cal.com embed API

## 🚀 Getting Started
